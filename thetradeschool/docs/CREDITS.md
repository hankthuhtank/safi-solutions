# Visual Asset Credits

**3D models and renders (V18).** The six trade models in `js/3d/models/` and every still in `assets/renders/` are original work generated from code for TradeSchool; no third-party models or textures are used. They run on three.js (MIT licence), vendored at `/assets/vendor/three.min.js` and shared with MotorAtlas.

Photos retired in V18 (the contactor, VFD, TXV and P-trap photos below, among others) stay in the repository but are no longer shown; see `js/content/v18-media.js` for the list and reasons.

## V15 changes (August 2026)

### Removed
19 files were removed because the image did not show what its caption claimed,
because the file was corrupt, or because it was not openly licensed. The full
list with a reason for each is stored in code at `js/content/v15-media.js`
(`D.removedMedia`), so the reasoning stays with the repository. Notable removals:
a watermarked commercial vendor advertisement that had been filed as an openly
licensed photo, a CGI stock render, and two corrupt files.

### Added — original technical diagrams
All authored for this project and released under the same terms as the rest of
the repository. Built reproducibly by `tools/media/build_diagrams.py`:

- `assets/reference/hvac/compressor_types.svg`
- `assets/reference/diagrams/refrigerant_transition.svg`
- `assets/reference/electrical/plc_architecture.svg`
- `assets/reference/electrical/photoeye_modes.svg`
- `assets/reference/industrial/cylinder_anatomy.svg`
- `assets/reference/industrial/belt_drive_ratio.svg`
- `assets/reference/industrial/gear_reduction.svg`
- `assets/reference/construction/header_framing.svg`
- `assets/reference/welding/arc_processes.svg`
- `assets/reference/plumbing/water_service.svg`

No third-party imagery was added in this pass. Wikimedia and Openverse were not
reachable from the build environment, so the gap left by the removals was filled
with original diagrams rather than with unverified files. To add photography
later, use `tools/media/wikimedia_media.py`, verify the licence on the original
file page, and record the required metadata here.
