# TradeSchool V10 — Visual First

## Intent
Make the product as visual as the available real media allows, and remove playground tools that look like toys.

## Visual expansion
- New `js/content/v10-visuals.js` maps every usable real photo and technical SVG onto every concept it can honestly support.
- Coverage moved from ~53 concepts to **113 concepts** with a dedicated visual asset.
- Shared photos keep concept-specific captions so the same image teaches different recognition points.
- Unit pages now surface a **Field + Technical References** strip at the top when unit-level visual clusters exist.

## Practice labs — hard prune
Only labs that teach a measurable cause-and-effect relationship without looking like made-up equipment remain in the catalog:

| Trade | Kept |
|-------|------|
| Electrical | Circuit Bench, Ladder Logic Trainer |
| HVAC | Refrigeration Cycle |
| Plumbing | Trap + Vent |
| Industrial | Hydraulic Force + Motion |
| Welding | Weld Parameter Window |
| Construction | Water Management (envelope) |

All other CSS toy simulations (load path blocks, framing builder, bearing health spinner, conveyor, shaft alignment, blueprint trainer, joint/defect toys, etc.) were removed from the learner-facing catalog. Render functions remain for deep-link safety only.

## Principle
A photo of real equipment or a clean technical diagram beats a cartoon simulation. Interactive tools stay only when they prove a relationship that text and photos cannot show alone.
