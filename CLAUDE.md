# Safi Solutions site

## Git and deploying

- Work directly on `main` and push to `main`. Do not create feature branches or pull requests
  for this repository unless explicitly asked in that session.
- A push to `main` is a deploy: it updates the live site at https://www.safisolutions.org.
- If a session starts on a `claude/...` branch, switch to `main` (`git checkout main && git pull`)
  before making changes, and push there.
