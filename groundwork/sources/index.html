About the bar’s shot

The espresso machine is a teaching model, not a physics simulation. Grind size and dose set how much the puck resists water; that sets pressure and flow. Ratio, resistance and channeling then set extraction and strength, calibrated so a dialed-in 1:2 shot lands near 20% extraction and 10% strength. Real coffees shift these numbers: use them to learn the direction of each change.
